# URL 截图工具

这是一个使用 Python 编写的桌面程序，可以在 Windows 上批量为网址生成网页截图。只需将多个网址逐行输入文本框，点击“开始截图”按钮，程序就会依次打开这些网页并将全屏截图保存到程序所在目录。

## 环境准备

1. 安装 Python 3.9 或更高版本。
2. 安装依赖：

```bash
pip install -r requirements.txt
```

首次运行时，`pyppeteer` 会自动下载 Chromium 浏览器，请耐心等待。

## 运行程序

```bash
python app.py
```

界面说明：

- 文本框：每行输入一个网址（支持不带协议的域名，程序会自动补全为 `http://`）。
- 按钮：点击后开始批量截图。截图完成后会在窗口底部显示状态信息，并在程序目录下生成以序号和域名命名的 PNG 图片。

若某个网址无法访问，状态栏会显示错误提示，程序会继续处理后续网址。
